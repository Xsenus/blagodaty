# Настройка Blagodaty Camp 2026

Документ для администратора: как после деплоя проверить поход, поменять ответственных, подключить Google таблицу и убедиться, что регистрация работает по новым правилам.

## 1. После деплоя

1. Задеплойте новую версию API и фронтов.
2. Перезапустите API.
3. При старте API сам применит миграции базы и заполнит базовые данные похода.
4. Откройте личный кабинет администратора: `/admin`.
5. Проверьте разделы:
   - `/admin/events` - событие, даты, цена, программа, контент.
   - `/admin/site` - контакты и Google Sheets.
   - `/admin/registrations` - заявки и статусы.

Миграция добавляет дату рождения каждому участнику в составе заявки. Для старых заявок дата основного участника переносится в первую строку состава.

## 2. Данные похода

Откройте `/admin/events`, выберите `Blagodaty Camp Лето 2026` и нажмите `Редактировать`.

Проверьте основные поля:

- цена: `18 000 RUB`;
- даты: `17 августа 2026` - `22 августа 2026`;
- мест: `35`;
- регистрация до: `10.07.2026`;
- оплата до: `13.07.2026`;
- размещение: палаточный поход;
- возраст: с 16 лет.

В этом же разделе можно менять:

- название и описание события;
- даты регистрации и самого похода;
- тарифы;
- расписание;
- медиа;
- контентные блоки публичной страницы.

## 3. Правила регистрации

Сейчас правило зашито на сервере и проверяется не только на фронте:

- участник должен быть не младше 16 лет на дату начала похода;
- участник 16-17 лет не может быть основным заявителем;
- если в заявке есть участник 16-17 лет, основным участником должен быть взрослый 18+ родитель или сопровождающий;
- дата рождения собирается у каждого участника.

На публичной форме и в личном кабинете флаг `16-17 лет` вычисляется автоматически по дате рождения.

Если когда-нибудь нужно поменять минимальный возраст, это не админ-настройка: нужно менять константы в backend-коде `EventRegistrationService`.

## 5. Google Sheets live-sync

Live-sync обновляет Google таблицу после:

- отправки гостевой заявки;
- отправки заявки из личного кабинета;
- смены статуса заявки в админке.

Черновики не синхронизируются, пока не отправлены.

### 5.1. Подготовить Google таблицу

1. Создайте Google таблицу.
2. Создайте лист с названием, которое будете указывать в админке, например `Registrations`.
3. Скопируйте ID таблицы из URL.

Пример URL:

```text
https://docs.google.com/spreadsheets/d/1AbCDEFghiJKLmnop/edit#gid=0
```

ID таблицы:

```text
1AbCDEFghiJKLmnop
```

Не вставляйте весь URL в поле `ID таблицы`, нужен только ID между `/d/` и `/edit`.

### 5.2. Создать service account

1. Откройте Google Cloud Console.
2. Выберите или создайте проект.
3. Включите `Google Sheets API`.
4. Создайте `Service Account`.
5. Создайте JSON ключ для service account.
6. Скопируйте `client_email` из JSON.
7. В Google таблице нажмите `Share` и добавьте этот `client_email` с правами `Editor`.

Без шаринга таблицы на `client_email` синхронизация будет падать с ошибкой доступа.

### 5.3. Включить в админке

Откройте `/admin/site`, блок `Google Sheets`.

Заполните:

- `Включить live-sync` - включено;
- `ID таблицы` - ID из URL;
- `Лист` - например `Registrations`;
- `JSON ключ service account` - весь JSON ключ.

Нажмите `Сохранить Google Sheets`.

После сохранения JSON не показывается обратно в админке. Если ключ нужно заменить, вставьте новый JSON и снова сохраните.

### 5.4. Проверить

1. Нажмите `Синхронизировать сейчас`.
2. Откройте Google таблицу.
3. Проверьте, что появились строки заявок.
4. Если есть ошибка, она появится в блоке Google Sheets в админке.

Синхронизация полностью переписывает указанный лист актуальными данными по заявкам текущего события.

## 6. Что попадает в таблицу

Таблица содержит строки по участникам, а не только по заявкам.

Основные колонки:

- статус заявки;
- контактное лицо;
- участник;
- дата рождения;
- признак `16-17 лет`;
- телефон;
- email;
- город;
- церковь;
- тариф;
- размещение;
- здоровье, аллергии, особые условия;
- комментарий;
- дата обновления.

Если в одной заявке несколько участников, в таблице будет несколько строк.

## 7. Excel выгрузка

В `/admin/events` откройте событие и нажмите `Скачать таблицу`.

Файл Excel содержит:

- лист заявок;
- лист участников;
- сводку.

В лист участников добавлена дата рождения каждого участника.

## 8. Карта активностей рядом с кэмпом

На публичной странице есть блок `Карта активностей` после блока `Место`.

Сейчас точки и цены задаются в коде публичного фронта:

```text
src/frontend/camp-web/src/components/NearbyActivitiesMap.tsx
```

Чтобы изменить или добавить место:

1. Откройте массив `nearbyActivities`.
2. Добавьте объект с названием, категорией, координатами, описанием, ценой, длительностью и ссылкой на источник.
3. Если нужна новая категория, добавьте ее в тип `NearbyActivityCategory`, `categoryLabels` и `categoryColors`.
4. Запустите `npm run build --prefix src/frontend/camp-web`.

Координаты указываются в формате:

```text
lat: 50.228723,
lng: 87.929919
```

Цены на экскурсии, заброски, сплавы и технику сезонные. Перед публикацией лучше открыть ссылки-источники в карточках и проверить актуальность.

## 9. Быстрая проверка перед запуском регистрации

1. Публичная страница открывается.
2. В публичной форме видны цена `18 000`, даты `17-22 августа`, `35` мест.
3. Нельзя отправить участника младше 16 лет.
4. Участник 16-17 лет требует взрослого основного участника.
5. Дополнительный участник требует дату рождения.
6. Контакты Михаила и Ильи видны внизу публичной страницы.
7. В админке можно изменить контакты и сохранить.
8. `Синхронизировать сейчас` обновляет Google таблицу.
9. Новая отправленная заявка появляется в Google таблице.
10. Смена статуса в админке обновляет Google таблицу.
11. Блок `Карта активностей` показывает карту, маркеры, цены и ссылки на источники.

## 10. Частые проблемы

### Google таблица не обновляется

Проверьте:

- включен ли live-sync;
- верный ли ID таблицы;
- существует ли лист с указанным названием;
- расшарена ли таблица на `client_email` из service account;
- включен ли Google Sheets API в Google Cloud;
- вставлен ли полный JSON ключ, включая `private_key`.

### Контакты не видны на сайте

Проверьте:

- включен ли блок `Показывать контакты на сайте`;
- активен ли конкретный ответственный;
- включен ли `Показывать в подвале`;
- есть ли хотя бы один канал связи с URL.

### Даты или цена на публичной странице старые

Проверьте событие в `/admin/events`. Публичная страница берет данные из базы, а не напрямую из `appsettings.json`.

Если данные в базе уже были вручную изменены, правьте их через админку.
